# Card-Not-Present Fraud Detection

An end-to-end machine learning model for detecting card-not-present (online) payment fraud, built on the IEEE-CIS Fraud Detection dataset.

**Status:** in progress — setting up the data pipeline.

## What this project will show

- Time-based validation that prevents leakage from future transactions
- Behavioral features built from each card's transaction history
- A model comparison from logistic regression to gradient boosting
- Probability calibration and a decision threshold chosen by business cost
- Model explanations with SHAP

Results, setup instructions and the full write-up will be added as the project progresses.
